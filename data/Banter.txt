# ============================================================================
#  Netsu iF — battle banter
#  Edit this file and save it: the next battle uses it. No export, no restart.
#
#  How a block looks:
#
#    [start] Cecilia + Eustace          <- said when a battle starts
#    Eustace: What he says.
#    Cecilia: What she says.
#                                       <- a blank line ends the block
#    [victory] Soran + Cecilia          <- said after a won battle
#    Cecilia: ...
#    Soran: ...
#
#  - Everyone named in the [ ] line has to be in the party (alive, for victory).
#  - Each line is   Name: what they say   (any number of lines, any order).
#  - [start replace] also hides the old plugin exchange between exactly those
#    characters (used once below, for Liliana + Lila).
#  - Lines starting with # are notes and are ignored.
#  - Names: Cecilia, Lila, Eustace, Ronald, Leticia, Flan, Noah, Sara, Liliana,
#    Soran, Juel, Silica, Lucia, Sophia.
#  - A typo in a name skips that block (Godot's Output panel says which line).
#  - Online: give the other players the same file, or they see other lines.
#    (Only the words differ; it can't knock the game out of sync.)
#
#  How often: battle-start banter has an 18% chance in normal battles (none in
#  Elite / boss fights); a victory exchange 25% after a win. Both are set in
#  the plugin (TA_RogueliteVictoryBanter: StartBanterChance / VictoryExchangeChance).
# ============================================================================
