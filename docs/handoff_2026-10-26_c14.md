# Handoff — Oct 26 (c14): Big Bang Crash explosion hits and launches high, Flan 5C box

**C# changed, so Build.** Old files are in `_backup_stage_select/pre_push_oct26_c14.zip`.

## Big Bang Crash (Flan 214BC: states 94 → 95 → 106 → 97)
- **Bug:** the slam (106) holds the opponent under Flan, so they land in a knockdown before the explosion (97). The Oct 26 evening rule "supers never hit a lying opponent" (`NetsuSuperOtg`) then made all four explosion hits whiff.
- **Engine fix:**
  - New `SakugaActor.NetsuSuperConnected` (rollback key 25). It's set in `HitConfirm` once the running super has hit, reset when a new move starts (`ExecuteMove`), and reset when she's out of her attack states.
  - `NetsuSuperOtg` lets a super that has already hit keep hitting the opponent it knocked down. A super that starts on a lying opponent still can't pick them up.
- **Launch** (`47_Hitbox_BigBangCrash_Boom_6`, the last explosion hit):
  - Knockback (−30000, 80000) / gravity 200000 → (−20000, 150000) / gravity 150000, for ground and air.
  - Airtime goes from about 0.8 s to about 2 s, then a hard knockdown, so Flan's 100-frame explosion state is over before they're back up.
