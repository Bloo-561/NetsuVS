# Handoff — Oct 26 (c12): 6C jump cancel, air throws for everyone

**C# changed (StanceManager), so Build.** The old Data, Stance and StanceManager files are in `_backup_stage_select/pre_push_oct26_c12.zip`. Everything else is new.

## 6C jump cancel
`StanceManager.NetsuJumpCancel` / `NetsuJumpCancelBlocked`: 6C now jump-cancels on hit or block, like 5A / 5B. 2B is still hit-only, and every other normal still can't jump-cancel.

## Air throws (Cecilia, Flan, Leticia, Noah)
- **Input:** same as the ground throw (`51_Input_Throw`, B+C), but in the air. Move "Air Throw", priority 7, `UseOnAir`. It's added at the end of each main stance's Moves list, so the existing move indices don't shift.
- **The engine already supported it:** a THROW box with `AirThrow = true` grabs an airborne opponent (`ThrowDamage`). No engine change was needed.

New files per character (P = CEC / FLN / LET / NOA):

| File | What it is |
|---|---|
| `Hitboxes/P_Hitbox_AirThrow_1.tres` | The ground grab box with `GroundThrow = false`, `AirThrow = true` |
| `AnimationData/P_AirThrow_AnimData.tres` | **Placeholder:** the ground throw animation using the air grab box. Tamaki will draw the real one. |
| `States/P_AirThrow.tres` | Whiff / startup. Keeps jump momentum, gravity every frame, lands into state 11 on touchdown, falls (state 10) when it ends. On a grab it goes to Air Forward, or Air Back if holding back. |
| `States/P_AirThrowForward.tres` / `P_AirThrowBack.tres` | Copies of the ground throw follow-ups. The thrower holds in place (MoveY 0) until the throw hit lands, then falls (gravity from 4 frames after the last hit window: CEC / LET frame 12, FLN / NOA frame 18). Lands into 11, or ends into Falling. The ground throw-hit animation is the placeholder. |
| `Moves/P_AirThrow.tres` | The move itself |

- **State indices added to each Data's States list** (air throw / forward / back): CEC 116–118, FLN 109–111, LET 111–113, NOA 112–114.
- **Victim:** the usual Grabbed state, which stops their velocity, so they hang in the air with the thrower. After that, the throw hit's air values apply. The c11 launch-gravity rule makes sure they fall.
- **Tech:** a break uses the existing ThrowBreak states. Idle switches to Falling when airborne, so nobody is left floating.
