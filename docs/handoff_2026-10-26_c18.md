# Handoff — Oct 26 2026, batch c18 (Big Bang Crash ending)

**Press Build** (C# changed: `engine/sakuga/Components/SakugaActor.cs`).

Problem: after Flan's Big Bang Crash (214BC) the opponent got up while she was still in her ending pose (stand, then
the sweat wipe, frames 40-100 of `97_FLN_S2_boom`), so they counter hit her.

Fix (engine, all fighters): `SakugaActor.NetsuHeldDownBySuper()`. A fighter lying on the floor stays down while the
opponent is still in a 3-bar super that has hit (`NetsuSuperActive && NetsuSuperConnected`, state type COMBAT):
- `NetsuGetUpWhenDue` waits;
- the lying state (Hit_Knockdown / Hit_Down) stops two frames before its end, so it can't roll into Hit_GetUp.
As soon as the super's last state ends (Flan back to idle), they get up as usual (Hit_GetUp, invincible). So Flan is
always free first. A super that whiffs or is blocked changes nothing.

No data files changed. Backup: `_backup_stage_select/pre_push_oct26_c18.zip`.
